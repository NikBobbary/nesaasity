# Nesaasity — 0 &rarr; 1 SaaS MVP Studio

High-voltage digital agency and MVP engineering studio for early-stage B2B SaaS & AI founders.

---

## Quick Start

Run the local development server with hot module reloading:

```bash
npm run dev
```

The site will be live at:
**[http://localhost:5173/](http://localhost:5173/)**

---

## Available Scripts

| Command | Description |
| :--- | :--- |
| `npm run dev` | Starts the Vite development server with instant HMR on `http://localhost:5173` |
| `npm start` | Alias for `npm run dev` |
| `npm run build` | Compiles and optimizes assets into the `dist/` directory |
| `npm run preview` | Locally previews the production build |

---

## Project Structure

- **`index.html`**: Production website for Nesaasity (Hero, Scope Simulator, Process, Capabilities, and Scoping Modal).
- **`styles.css`**: Complete design system with Chartreuse & Slate tokens, Kumbh Sans & Playfair Display typography, and 1280px / 960px / 480px responsive breakpoints.
- **`assets/`**: High-resolution generated UI previews for Cognix AI, Hyperflow, Layered Health, and the Studio Workstation.
